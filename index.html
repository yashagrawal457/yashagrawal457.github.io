About

A bit about me

I studied Math and Computing at IIT Kharagpur, which is a roundabout way of saying I like problems that sit somewhere between logic and code. These days that shows up at KAL ATM Software, where I help build the systems behind ATM networks for four banks, software that quietly needs to work correctly every single time, across thousands of machines and tens of thousands of transactions a day. Before that, I spent a summer at BNY Mellon building a pipeline that generated realistic synthetic financial documents for training data. Outside of work, it's a mix of screens and not-screens: I'm often deep in some GenAI side-project, but you'll just as likely find me on a cricket field, doing laps in a pool, or a few episodes into a show.

Projects

Things I've built for fun

AskDoc

GitHub ↗

A chatbot that actually reads your PDFs. I got tired of ctrl+F-ing through long documents, so I built AskDoc to combine retrieval-augmented generation with LLM function calling. It grounds its answers in whatever PDF you upload, using sentence-transformer embeddings for semantic search, and can reach for a calculator or a date lookup mid-conversation instead of just guessing.

ChessMate

GitHub ↗

A chess engine I built mostly to see if I could. No machine learning here, just a minimax search with alpha-beta pruning, playing legal, sensible chess by searching the game tree efficiently enough to think a few moves ahead without taking forever.
